## Def & Entity Intelligence

- **kbengine-def language & grammar** — `.def` files get a dedicated language id, bracket rules and a TextMate grammar — (evidence: package.json#contributes.languages, package.json#contributes.grammars)
- **Real-time .def diagnostics** — unknown types / Flags / DetailLevel values, duplicate property & method definitions, missing Type/Flags fields, with a master switch — (evidence: package.json#configuration `kbengine.diagnostics.*`, `kbengine.enableDiagnostics`; src/defAnalyzer.ts; under `kbengine.core.backend=rust` the corpus-derivable face is served by kode-server asynchronously after the synchronous first paint — TS face replaces its own message keys with the Rust face, keeps foreign codes (lint merges, registered-type-missing-python-file disk probe), any diagnostics sub-knob off falls the whole face back to TS — src/languageProviders/validation.ts `serveRustDiagnosticsFace`/`mergeRustDiagnosticsFace`, crates/kode-server/src/diagnostics.rs)

- **Quick Fix: unknown type correction candidates** — the unregistered-type diagnostic (stable code `kbengine.unknownType`) offers QuickFix replacements drawn from registered types only (builtins + types.xml + entities), case-normalized edit distance ≤ 2, distance-sorted and capped at 5; edits touch only the current document, no declarations are auto-created
   — (evidence: src/languageProviders.ts `KBEngineTypeCodeActionProvider`, `UNKNOWN_TYPE_DIAGNOSTIC_CODE`)
- **Code Action: generate empty implementation for unimplemented def methods** — acting on a def method declaration whose owner script exists but lacks the method, offers a single Refactor action whose title shows the target file and insertion line; the skeleton is `def name(self, arg0..argN)` with `pass` body, `<Arg>` count driving the parameter list;
   the insertion point is computed from the target file's current text (open buffer preferred); already-implemented methods (same query face as Go to Implementations) are not offered again — (evidence: src/languageProviders.ts `KBEngineMethodImplementationCodeActionProvider`; src/entityMapping.ts `listOwnerScriptFilesForIdentity`)
- **Config contract diagnostics (workspace config layer)** — a read-only workspace-level contract check over the files kode never validated before: `.kbengine/debug.json` (empty/missing `debug.components`, known components' telnet port missing or off the engine default 31000/32000/33000/34000/40000/50000/51000, a commented-out telnet section, unparsable JSON), `python.analysis.extraPaths` (`../..` double-ups that skip past the engine dir for `kbe/typings`, entries pointing at nonexistent directories, absolute `python.analysis.extraPaths` entries `kbengine.configContract.extraPathsAbsolute`), `.gitignore` missing the `.kbengine/` managed-dir entry, and CLAUDE.md/README-declared telnet passwords/ports conflicting with the actual `debug.json` values — each a Warning with bilingual fix hints, anchored on the offending file, behind `kbengine.configContractDiagnostics` (default on); scanned on activation, on open/save of the contract files, and via a FileSystemWatcher change-rescan (the `DebugConfigManager.configWatcher` pattern); gated on the `.kbengine/` managed dir so non-KBEngine workspaces stay silent — the lever that turns the intranet-machine config incidents (docs/analysis/intranet-env-audit.md) from 'human review + live reproduction' into 'save-and-flagged'

- **Python receiver-None diagnostics** — `self.cell`/`self.base`/`self.client` member use without a null guard (positive `if`, early exit, alias, `hasattr`) flags a Warning citing the engine getter source; calling a `.def` method via a receiver whose section does not declare it flags a section mismatch;
   the receiver-none Warning carries code `kbengine.receiverNone` with two QuickFixes — a wrap guard (`if self.<receiver>:` wrapping the current and following same-level statements, re-indented, continuing execution; primary) and an early-exit guard (`if not self.<receiver>: return` above the use line) — matching the diagnostic's own guard grammar so the warning clears on recompute (2026-10-29; wrap primary 2026-10-30); the async entry consumes a version-keyed shared parse (`asyncDocumentParse`: cache hit is zero-parse, misses route through the large-file worker at ≥256 KiB so the extension host never runs a whole-file sync parse, and an unavailable/shared-stale round aborts without publishing) — (evidence: package.json#configuration `kbengine.receiverNoneDiagnostics`; src/receiverNoneDiagnostics.ts `buildReceiverNoneGuardEdit`/`computeReceiverNoneFindingsAsync`; src/pythonClassIndex.ts `asyncDocumentParse`; src/languageProviders.ts `KBEngineReceiverNoneGuardCodeActionProvider`)
