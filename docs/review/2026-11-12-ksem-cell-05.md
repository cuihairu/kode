## 实现

**TS 纯模块(backend/cellDataKeyAccess.ts 新增)**——与补全面分工:补全只认
开引号+片段(键入中),本模块只认**完整闭合**的字符串字面量键:

- `cellDataKeyAccessAtPosition(lineText, character)`:落点是否在
  `self.cellData[...]` / `self.cellData.get(...)` 的键内容区间内
  `[keyStart, keyEnd)`(keyEnd 为尾后一列=闭引号列,闭引号/闭括号上的
  落点不命中);返回解引键+区间+形态。同行探测,动态键(`[var]`/拼接/
  f-string)不静态关联→null;
- `scanCellDataKeyAccesses(text)`:全文扫描,词法掩码(`buildPythonCodeMask`
  自 globalDataIndexCore)剔除注释/普通字符串/三引号字符串里的伪访问;
  只收当前行闭合的访问;返回 `{key,keyStart,keyEnd,line,kind}`;
- `isCellDataKeyInsideLineComment(lineText, keyStart)`:落点前引号外 `#`
  判注释伪访问(与 globalData 同口径);
- 转义解引:单字符(\\ \' \" \n \t 等)+八进制+`\xNN`+`\uNNNN`+`\UNNNNNNNN`;
  非法/不支持转义 → 该访问跳过(不改写键值、不硬猜)。

**cellDataCompletion.ts**:新增 `collectCellDataDefUniverseWithCategory`(def
宇宙闭包带来源类别 `{name,category,text}`,供跳转按类别解析 `{from}.def`);
原 `collectCellDataDefUniverse` 变薄壳转调(补全面零感知)。

**跳转接线(languageProviders/pythonDefinition.ts)**:`provideDefinitionTracedImpl`
GLOBDATA-001 分支之后、`isPythonCodePosition` 守卫之前(键是字符串字面量,
该守卫会把其内位置判 skip)——落点命中键且非注释伪访问时:角色/实体面
(scripts/cell|base/<Name>.py)内取 def 宇宙闭包+Rust 键宇宙,命中同名键且
kind≠builtin 且有 sourceFile 时,按 `sourceFile.replace(/\.def$/,'')` 的 def
名在闭包内定类别 → `findDefinitionFileByCategory` 定位真实路径 → 落点行
`(sourceLine ?? 1) - 1`(Rust 1 基 → vscode 0 基)。诚实边界:内建键(引擎
文件,不在 workspace)不跳转、不伪造声明;未知键/非实体脚本面/键宇宙不可用
→ 交回常规链。`JumpLayerTrace.layer` 字面量联合新增 `'cellData-key'`。

**引用接线(languageProviders/references.ts)**:`provideReferences` python
分支 GLOBDATA-001 之后——落点命中键且键宇宙含该键时,`findEntityScriptFile`
定位当前实体(cell/base 面)脚本,扫其全文取同键全部字面量访问点(含自身;
同文档用 document.getText() 脏缓冲区,否则读盘);返回 Locations。实体身份
隔离:只扫当前实体自身脚本,不跨实体;未知键 → 交回下方属性引用链(如实,
不伪造声明);内建键是引擎自塞面,脚本内同键访问仍可列出。

## 坑

1. 键内容区间为 `[keyStart, keyEnd)`:初版探测条件 `character <= keyEnd`
   会把闭引号列算进键内(F12 在 `"hp"` 闭引号上误命中);改严格 `< keyEnd`
   (cellDataKeyAccess.ts:344)。
2. `JumpLayerTrace.layer` 是字面量联合:新层必须同步加 `'cellData-key'`,
   否则 tsc TS2322(首次编译红即捕获)。
3. prove-red 跨文件:新模块是未跟踪文件,净检出 HEAD worktree 时需手动
   复制新模块+改动版 cellDataCompletion(否则 import 红,测不到 provider
   行为红);provider 分支缺失才是要证的行为红。
