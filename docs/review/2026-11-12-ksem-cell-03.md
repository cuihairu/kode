## 实现(cell.rs 增面)

**引擎事实**(design §2:组件另建 Cell 数据):每组件槽在 cellData 下成键,
值 = 组件 def 的 **Cell 侧字段** 子字典。

- `ComponentCellData{slot, component_type, file, line, fields, nested,
  issues}`——槽名 = cellData 的键;`file/line` = 组件声明跳转面
  (BAS-05 `ComponentView` 增 `file/line`,additive);
- **仅组件 Cell 侧字段**:子字典字段按 `flag_domains` cell 域过滤
  (BASE/CLIENT 域不纳入,与 CELL-01 同域位真值);
- **递归展开**:组件 def 的组件段再展开(嵌套槽 `cellData[槽][槽][字段]`);
  组件 def 的继承/接口 cell 字段同样展开(BAS-05 `EntitySnapshot` 复用);
- **环安全双保险**:visited 路径(组件类型名在 path → 记
  `component-cell-cycle` 事实,不 hang)+ 深度界
  `COMPONENT_CELL_MAX_DEPTH=8`(溢出记 `component-cell-depth-overflow`);
- **诚实边界**:组件类型缺(owner 级 missing-component-type 已记)/组件段
  无类型 → 槽面保留、字段不造。

`CellDataShape.component_cells` = 展开面(声明序,与 `component_slots`
平槽面同序对应)。
