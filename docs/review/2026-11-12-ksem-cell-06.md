## 实现

**TS 纯模块(backend/cellDataReadType.ts 新增)**——与 CELL-05 读取探测分工:
本模块做**读取类型**推导(键宇宙 typeLabel → Python 注解;get 按存在性/
default 算可空/联合),消费面是 typeInlayHints 的局部变量/表达式提示。

- `scanCellDataKeyOperations(text)`:全文扫描并**分类**读/写/删(`self.cellData[
  "k"]` 后接 `=` 非 `==` → write;`del` 前缀 → del;`.get(...)`/裸下标 → read);
  复用 `parseCellDataKeyAccess`(CELL-05 模块新增导出),词法掩码剔伪访问;
- `cellDataKeyProvablyPresent(ops, target, lines, keyInUniverse)`:同一键最近
  写/删(自目标向上,作用域限,与 findNearestWrite 同口径)定状态:写 → 必有,
  删 → 必无;无写/删 → 初始(def 字段/内建/组件槽必有,未知键必无);
- `resolveCellDataReadType({accessKind, fieldAnnotation, hasDefault,
  defaultAnnotation, provablyPresent})`:下标 → 字段型(下标缺失抛 KeyError 恒
  非空);get 且必有 → 字段型(default 不可达);get 且非必有、无 default →
  字段 | None;get 且非必有、有 default(类型已知)→ 字段 | default(去重);
  get 且非必有、有 default(类型未知)→ null(不能精确并集,不猜);
- `cellDataHintPosition(lineText, op)`:纯赋值 RHS(`x = <读表达式>` 且读取
  表达式恰为整个 RHS)→ 提示落目标变量后;其余(裸表达式/更大表达式)→ 落
  读取表达式尾后一列。

**cellDataKeyAccess.ts(增补)**:导出 `parseCellDataKeyAccess`/`ParsedKeyAccess`,
`ParsedKeyAccess` 增 `defaultExpr`(get 第二个实参文本,无 → null)。行为零
变化(导出函数仍剥出子集面),CELL-05 20 例回归保绿。

**inlay 接线(typeInlayHints.ts)**:`PythonTypeInlayHintsProvider` 增
`collectCellDataReadHints`(typeData 开关同款,顶部已拦)——角色/实体隔离
(cell/base 面),键宇宙装配与补全同源(cellScriptRoleAndEntity +
collectCellDataDefUniverse + findDefinitionFileByCategory 读 def +
fetchCellDataKeys RPC),按文档版本键缓存(flowVersionKey,有界 200 防膨胀,
同版本多次渲染零重复 RPC);每读点:键宇宙命中 + typeLabel 解析非 Any
(resolveEntityAnnotationTypeWithReason)→ 存在性 + get default 类型
(inferDataDictValueType)→ resolveCellDataReadType → 落点出 `: <type>`
(kind=Type)。写/删只做存在性(写类型校验归 CELL-08)。

## 验收(CELL-06 三点全)

| 验收点 | 测试 |
| --- | --- |
| 下标读取类型传给局部变量和表达式 | provider:`x = self.cellData["hp"]` → `x: int`(局部变量);裸表达式 `foo(self.cellData["hp"])` → 表达式尾后 `: int`(表达式) |
| get 根据可证明存在性及 default 计算可空/联合 | `get("hp")` 必有(def 字段无删)→ `int`;del 后 → `int | None`;del 后 `get("hp","none")` → `int | str`;同型 default 去重 `int` |
| 删除后不能沿用必有键 | `del self.cellData["hp"]` 后 `get("hp")` → `int | None`(不再当必有);再写 `self.cellData["hp"]=1` 后 → `int`(恢复必有) |

测试 28 例新增(纯模块 20 + provider 全链 8)。诚实边界:未知键/类型落 Any/
get default 类型未知 → 不出提示;client/bots 不接管;无 gate 不造键。
