## 实现(设计 §4「增量」:依赖边驱动精确失效)

`DependencyGraph` = producer → consumers **反向依赖**图,两向记录互补
(`reverse`/`forward`),每条边幂等,消费者集合 `BTreeSet`(确定性序):

- `add_edge(producer, consumer)` 登记反向依赖;
- `consumers_of` / `producers_of` 查询(升序;无 → 空);
- `invalidate(producer)` = 直接消费者(相关项,单文件变更只失效这些,
  不触全仓重扫);
- `invalidate_closure(producer, max_hops)` 级联失效:有界 BFS,边距离 ≤
  max_hops(直接消费者 = 距离 1;0 → 空,producer 自身不计),visited 环安全,
  结果按发现序去重;
- `remove(doc)` 删除对称清理(作 producer 清出边 + 作 consumer 清入边),
  无悬空键残留;`edge_count`/`is_empty` 诊断。

producer 分类由 `producer_kind` 按 URI 扩展名:`.def`→Def、`.types`→Types、
`.xml/.yaml/.yml/.json`→Config、`.py`→Python,其余 None——分类是调用点
事实(与「图不重复编码分类」一致)。
