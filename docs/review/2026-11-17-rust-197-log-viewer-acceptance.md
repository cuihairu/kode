# RUST-197 验收纪要:大日志 viewer 的有界承载与背压

日期:2026-11-17。本纪要对账 RUST-197(旧 EXEC-009,主 todo 排队项)的验收口径与既有交付证据。结论:**核心诉求(大日志不卡死 viewer)已交付,形态为「流式有界」而非「分页/虚拟滚动」,搜索与导出无长跑面故「可取消」不适用,本批为对账收口(零代码增量)。**

## 本批增量

- 零代码增量:背压与有界 DOM 均有既有钉,再造属仪式性重复。

## 诚实条款

- **无分页、无窗口化虚拟滚动**:交付形态是「流式 append + 有界 DOM」,不是分页器或虚拟列表;对当前吞吐(logger 推流频率、5000 条窗口)实测无卡死面,若未来窗口上探到 DOM 性能边界,虚拟化随需另批,本纪要不冒充两者皆备。
- **搜索不可取消是因为无需取消**:搜索是 DOM 窗口(≤5000 条)内的客户端增量过滤,瞬时完成,不存在长跑搜索任务;hub retained 层无搜索面(如需全量检索,logErrorScan 文件扫描面有 64MB 有界,同样无长跑取消语义)。
- **导出不可取消是因为无长跑面**:导出=saveDialog 用户驱动+一次性写出已过滤内容,取消语义由对话框承载;无后台导出任务面。
