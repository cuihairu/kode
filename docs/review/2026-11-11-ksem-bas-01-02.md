## 二、KSEM-BAS-02 引擎契约版本登记

引擎基线：`../kbengine` @ **`3082ab5`**(`fix(pyscript): bound vector repr writes by remaining buffer size`)。引擎版本切换时，本表所有契约必须复核后再采用。

| 契约 | 引擎证据(以 3082ab5 核实) | 角色/行为 | 消费方 |
| --- | --- | --- | --- |
| cellData 初始化 | `kbe/src/server/baseapp/entity.cpp:250` `Entity::createCellData` | 有 Cell 部件才创建；字段取 Cell 属性描述；组件另建 Cell 数据；额外加入 position/direction | KSEM-CELL-01/02/03 |
| Cell 获得后属性可见性 | 同文件 `:1014` `onGetCell`；`destroyCellData` | 脚本回调前删除 self.cellData；内部备份字典仍保留；创建调用异步，不能立刻视为有 Cell | KSEM-CELL-11/12 |
| 持久化回调参数 | 同文件 `:1397` `onWriteToDB` | 参数来自内部 cellDataDict_，可能为 None；不等同脚本 self.cellData 可访问 | KSEM-CELL-13 |
| 远程方法角色 | `kbe/src/lib/entitydef/entity_call.cpp:83` | 按 CELL/BASE/CLIENT 及转发类型查不同方法表；客户端受 Exposed 限制；组件另走槽解析 | KSEM-RPC-01/02/04 |
| RPC 参数 | `kbe/src/lib/entitydef/method.cpp:72` | 参数数量和类型按 checkArgs，特殊 caller offset 必须区分上下文 | KSEM-RPC-06/07 |
| 固定字典对象契约 | `kbe/src/lib/entitydef/datatype.cpp:2408/2435/2500/2596` | implementedBy 对象与字典经 createObjFromDict/getDictFromObj 转换；普通 FIXED_DICT 检查键集合与字段类型 | KSEM-SER-03/04/05 |
| ENTITYCALL 类型 | 同文件 `:1484` | 接受 EntityCall、None 或实际 Entity；字段类型本身不指定具体实体 | KSEM-RPC-01 |
| 创建 API | `kbe/src/server/baseapp/baseapp.cpp:959` 起 | 各 API 返回与回调不同；params 开放性及字段路径逐个核实 | KSEM-CREATE-01/03/04 |
| spaceData | `kbe/src/server/cellapp/spacememory.cpp:703` 起 | key/value 字符串及受保护 _mapping；空间身份不能丢失 | KSEM-DATA-05/06 |

**边界(不能混淆)**：cellData 为普通 Python dict，允许脚本附加键；动态键/动态反射/复杂自定义序列化/不确定接收者均不得以猜测生成硬错误；JSON 解码无普遍固定结构；pickle 恢复对象不提供可静态枚举字段契约。

**待核实清单**(未穷尽，分别列任务)：运行时跨进程关联字段、不同创建 API 完整回调签名、所有内建 CellData 键、项目自定义编码/配置函数、客户端语言适配。
