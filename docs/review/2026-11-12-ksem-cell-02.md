## 实现(cell.rs 增面)

**独立引擎来源**(不与 def 字段混装):

- `BuiltinField{name, shape, source}`——`source` 为引擎取证
  (`server/baseapp/entity.cpp:250`,createCellData 把该键塞进 cellData 的
  引擎面;与 TS `entityBuiltinProperties.ts` 同源口径);
- `BuiltinShape::Vector3{axes}` 初始形态:position 轴序 x/y/z、direction
  轴序 roll/pitch/yaw(引擎建表六列同源:sm_0/1/2_position → position.x/y/z、
  sm_0/1/2_direction → direction.roll/pitch/yaw,databaseSchemaCore
  同面已核);脚本可见类型 `Vector3Like`(修正版 pyi
  _KBEngine_common.pyi:22 `Union[Tuple[float, float, float], Sequence[float]]`),
  `type_label()` 与 TS entityBuiltinProperties 同标签。

**封闭表**(核对后才加入):`builtin_cell_fields()` 恒 = [position, direction]。
核对链:design §2(entity.cpp:238/250 createCellData 额外加入
position/direction)+ 引擎建表六列。其余 cellapp 内建属性(spaceID/
controlledBy/topSpeed/topSpeedY/layer/volatileInfo/allClients/otherClients/
isWitnessed/hasWitness/isOnGround——TS entityBuiltinProperties.ts 已核为
**Entity 属性**)未核对为 **cellData 键** → 一律不入表(不猜;核对后按
CELL-02 口径增补,doc comment 在案)。

**接线**:`CellDataShape.builtins`——有 Cell 部件才创建 cellData → 无部件
恒空;有部件恒在(与脚本面无关,脚本缺失不影响引擎行为只影响分析可用面)。
def 字段面与引擎内建键面**分账不混装**(合并裁决归 CELL-05 键跳转/引用)。
