## 修通(ruff 0.0.20 真实 API,均经 registry 源码核实)

1. **表达式变体名**:`Expr::If`(非 IfExp)/`Expr::Generator`(非 GeneratorExp)/
   字面量族 `StringLiteral/NumberLiteral/BooleanLiteral/NoneLiteral/BytesLiteral/
   EllipsisLiteral`(非 `Constant` 一统);
2. **字段形状**:`ExprCompare{operands}`(无 left/comparators)、`DictItem.value`
   非 Option、`StmtIf.elif_else_clauses`(无 orelse)、`ExceptHandler` 为枚举
   (解构 `ExceptHandler::ExceptHandler(h)`)、`Ranged` trait 在 ruff_text_size;
3. **无 Display 的形态**:`Number` 枚举(Int/Float/Complex)无 Display 实现
   (有 Display 的是私有 `int::Number`)→ Int/Float/Complex 分支手写;
   `BytesLiteral` 无 as_str(Deref `[u8]`)→ 逐段 `from_utf8_lossy`;
4. **F-string**:单段 `as_single_part_fstring()` + `elements.interpolations()`
   取插值表达式。

## 行为补齐(驻留签名声明的意图,sketch 未实现)

`walk_expr(ast, e, out)` 驻留版本从不 `push`——`out` 参数只被递归传递,
Expr 层写点(海象赋值)从未登记,整棵遍历为死代码。clippy
`only_used_in_recursion` 抓住的正是这一点。按签名意图补齐而非 allow 掩盖:

1. **海象赋值**(`x := v`):walk_expr Named 臂登记(目标名 span 键,同行
   列序成立);
2. **元组/列表解包**(`a, b = ...`):语句层 Assign 臂逐名登记,位置 = 各自
   名 span(同一 RHS 起点无法区分同包内列序);嵌套 Tuple/List 递归展开,
   Starred 取内层名(`a, (b, *rest) = ...` → a/b/rest 三事件);
3. **其余语句级绑定形态**(驻留只走 Assign/AnnAssign/AugAssign):
   - for 循环变量(`for k, v in pairs` 解构展开,值形态 = iter 表达式);
   - match case 模式绑定(`case (x,y)`/`[a,*rest]`/`{'k':v}`/`C()`/`str() as s`
     → x/y/a/rest/v/s;`_` 通配不产生绑定;As/Star/Mapping.rest 为直接名);
   - with-as 变量(`with open(p) as f`,值形态 = 上下文表达式);
   - except-as 变量(`except ValueError as e`,值形态 = 异常类型表达式;裸
     except 无类型 → Unknown("bare-except"));
4. **位置键语义(如实)**:单名 Assign 沿驻留语义键 RHS 值表达式起点;
   解包/for/match/with/except 目标键各自名 span;Ann/AugAssign 键目标 span
   (驻留);三种键位共存——同行语句间列序全部成立,语句内键位不统一为已知
   边界;
5. **local_binding_at 签名**:改收 `events` 切片(调用方复用已收集事件,
   不重复走树);events 须为 `collect_assign_events` 产物(升序保证「最近 =
   最后匹配」),文档注明。
