# QA-005 大仓及图资源预算测量(2026-11-18)

任务:QA-005(旧 KSEM-QA-05)——测量大仓及图资源预算。验收:测试冷/热态、索引重建、长 RPC 同时运行与大图展开;预登记阈值和样本,不挑最快一轮。

## 方法

套件 `tests/largeRepoBudgetE2E.test.ts`(真实二进制,缺失 skip),合成仓临时目录:200 继承实体(`Ent0..199`,各 20 属性,`<Parent> Base{n%10} </Parent>`)+10 基类(`Base0..9`,各 20 属性)+`entities.xml` 全量注册,合计 210 def。四臂:

1. **冷态全仓装载**:新 gate/spawn,镜像全仓 210 文件计时;随后首 hover(`Ent0` hp)计时。
2. **热态连续 hover**:20 轮跨实体轮转(`Ent10..29`),样本全量进分位数。
3. **索引重建**:gate dispose 后重建(新进程),全仓镜像(version 2 走 didOpen 重发)+`beginBackgroundScan(210)`+`scanComplete(210,0)` 闭环计时。
4. **大图展开**:`buildDependencyGraphInRust(root)`(210 实体继承图)与交互 hover 并发——图在途时 hover 立即发出,断言预算内返回(长 RPC 不冻结交互);图节点/边规模断言+构建总链计时。

## 阈值预登记(预算上限语义,非实测值)

- 热态 hover 与图在途 hover:P99 < `INTERACTIVE_SERVE_BUDGET_MS`=2000ms(交互预算=设计截止)。
- 冷态装载/重建/图构建总链:< 30000ms(冷路径硬上限)。
- 图规模:nodes ≥ 210(全部注册实体入图)。
- 样本全量进分位数,不挑最快一轮;超阈值即红(阈值在套件内钉死)。

## 口径边界

- **内存面**:rust 服务器无 RSS 回传(仅 health `uptime_ms`),资源预算以耗时+图规模(nodes/edges)钉;内存预算属后续车道(需服务器回传字段)。
- 节点数 420=210 实体注册节点+210 def/实现节点(rust 图含 kind 分面节点),edges=210 继承边(`Parent` 链);规模断言取 `nodes ≥ 210`(注册面下限)。
- 大图在途并发验证了 executor 并发调度下交互不被冻结(rust 侧取消/容量面 CORE-007+RUST-072);hover 预算语义为单请求截止(超时降级回 TS),不是并发调度保证。
