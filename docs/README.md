# Kode 文档

Kode 是一个面向 KBEngine 项目的 VSCode 扩展，覆盖 `.def` 语言支持、诊断、跳转、实体浏览、日志、监控、依赖图和代码生成。

- [完整配置说明](./guide/configuration.md)
- [开发与发布](./guide/development.md)

## 文档开发

```bash
pnpm install
pnpm run docs:dev
```

构建静态文档：

```bash
pnpm run docs:build
```
