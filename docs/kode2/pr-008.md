## 类型图模型

- 节点(SEM-002 基础面):`Alias{name,target}`、`Array{name,element}`、
  `FixedDict{name,implemented_by,field_refs}`、`UserType{name}`(实体 .def)。
  内建标量不建节点(引用终点);同名先到先得(TS Map 同口径)。
- 边(IDX-002 补充面):`AliasTarget` / `ArrayElement` / `Field` / `TypeRef`(属性)/
  `ComponentOf` / `Inherits`。
- 链求值:别名链(别名 → 非别名终点)与继承链(实体 → 根)均有限步 + 显式状态
  `resolved | cycle | unknown | missing`(环截断在重复点前,绝不死循环,IDX-005 同款)。
- 全图环检测 `find_cycles`:对全部「终点可解析成节点」的边做迭代式三色 DFS,
  每条回边报告一条环路径,结果排序去重、输出确定。

## 环检测 / 继承链样例(单测即文档:`tests/types_units.rs`)

- 别名环:`<A>B</A><B>C</B><C>A</C>` → `resolve_alias_chain("A")` =
  `{chain:[A,B,C], status:Cycle}`(截断在重复点前);`find_cycles()` 报告 `[A,B,C,A]`。
- 继承链:`EliteMonster→TrainingMonster→Monster→Avatar` →
  `{chain:[EliteMonster,TrainingMonster,Monster,Avatar], status:Resolved}`;
  `Orphan→GhostParent`(未注册)→ `Missing`;`LoopA↔LoopB` → `Cycle`。
- 自环:`<SELF>SELF</SELF>` → `find_cycles()` 报告 `[SELF,SELF]`。
