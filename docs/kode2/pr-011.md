## 关键口径(与 TS 面逐条对齐)

- 判面只接管六面条目集相关上下文:def 顶层/接口段/属性子标签(Type、Flags
  等位)不接管 → null 结果(LSP 允许),不与 TS 既有 provider 抢面;
- 过滤:fragment 大小写敏感 startsWith(确定性优先,双轨同规则);开标签/
  取值各出**全量点 + 名前 2 字符过滤点**两场景,过滤与全量面都被对拍覆盖;
- 词字符 = ASCII `[A-Za-z0-9_-]`(对拍抓出:Rust `is_alphanumeric` 会把 CJK
  注释里的伪标签入栈,已改 ASCII 口径与 TS 正则一致);
- 实体条目集 = **def 语料注册名**(非 entities.xml 注册行),与 hover 的
  defFile/defExists 面同源;detail = 语料 rel 路径;
- 类型面先于别名面;各面内同名去重首见保留(路径字典序 = 首写优先);
- 标签栈为行级扫描(完整 `<X>`/`</X>`,`<X/>`/`<!--` 注释与未闭合尾标忽略),
  与 TS 复算同规则(对拍抓出并修正 TS 侧 `i=rel+2` 越位笔误,双侧规则一致)。
