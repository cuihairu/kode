## 行为差异(如实声明)

1. **边界内锚点降级是 kode-root 扩展**:TS 深扫描不做 submodule/vendored 概念;对拍面只覆盖 TS 可表达的锚点集(降级不改变锚点集成员,只影响解析),因此对拍仍逐字段一致。
2. **显式配置进入解析链第一级**:TS 中显式配置在 layout 装配层与发现兜底汇合,本单把两级显式化进 `ExplicitConfig`(验收语义与 TS 管理器口径一致:原值探针命中优先)。
3. **引擎源码根/消息表缺失 = informational**:纯资产工作区常态,不计问题(与 TS 批129 状态口径一致,TS 未把这两项列为 anchor 字段,此处为报告结构化扩展)。
4. **符号链接跟随模式**(`ScanOptions::follow_dir_symlinks`)是 kode-root 新能力(挂载环/别名收敛场景),默认关闭 = TS 口径,不参与对拍。
