## 增量 rebuild 计数实测(release,本机,2026-10-23)

`cargo run -p kode-index --release --example bench_index -- .`(200 文件合成工作区:
140 def + 20 entities.xml + 20 types.xml + 20 alias.xml,多根身份模型):

| 场景 | rebuild 计数 |
|---|---|
| 首扫 200 文件 | **200**(每文件恰 1),入库 1200 符号,generation=1 |
| 全量二扫(同内容) | **0**(cache_hits=200),generation 不变 |
| 单 def 编辑(±1 属性) | **1**(removed=8 → added=9) |
| 批量重提交 200 文件(其中 10 def 实际变化) | **10**,整批 generation 只 +1(原子) |
| 删除 5 def | 0 rebuild,移除 50 符号,倒排/继承边同步清空 |

单元级同构断言(6 文件工作区):首扫 6 → 二扫 0 → 单改 1 → 批量 1 次 generation;
另覆盖环终止、删除/改名清理、根级 scoped 失效、非声明文件显式回报(ARCH-004)。
