## 关键口径(与 TS 面逐条对齐)

- defsRoot 探测 = TS `findEntityDefsRootFromFile` 同规则(向上找含
  entities.xml 的目录,文件在 `entity_defs/` 内时根取该子目录);
- def 视图**按路径**键(def_files),父/接口/组件存在性按语料路径判定——
  与 TS 逐路径读文件同语义;跨语料同名实体(Account/Monster/Avatar 在
  demo-assets/parity-project/electron-ws 各有一份)互不串扰(对拍抓出后修正);
- entities.xml 注册项 defFile 面 = 语料内首见路径(语料序 = 字典序,与 TS
  collectCorpus 同序首写优先);未命中回退约定名 `<Name>.def`(TS 同口径);
- 环截断:parent 文件重复出现时截断并 `cycleTruncated=true`(visited 集,
  与 TS buildDefChain 同;绝不死循环);
- `<Parent>` 标签名/取值词命中即给链面(无 Parent 也如实呈现空链),
  触发面与 TS `getDefChainHover` 一致。

## 响应链样例(fixture 实测,`hover-parity.json` kbengine-demo-assets Monster.def)

```
hover(word=Monster, line=1) →
symbol:    { name: Monster, kind: entity, section: Entity }
signature: { parent: Avatar, … }
inherited:
  parentChain: [Avatar(exists)]            # → demo-assets Avatar.def
  interfaces:  [ROLE(exists)]              # 闭包平铺(接口不跟随 Parent)
  components:  [Inventory(exists)]         # 闭包平铺
  cycleTruncated: false
  members:
    - Avatar: properties [name:STRING, level:UINT32, hp:UINT32,
                          position:VECTOR3, sight:UINT16, skillSlots:ARRAY]
              methods [reqCastSkill(base), respawn(cell), onHPChanged(client)]
```

环样例(单测 `chain_cycle_is_truncated_and_reported`):LoopA→LoopB→LoopA →
`parentChain=[LoopB, LoopA], cycleTruncated=true`,有限步终止。

`[{Nobody, exists=false}]`,成员如实空、不虚构。
