## 1. 双轨切流开关:设计 + 实现

### 1.1 配置键(package.json contributes.configuration)

| 键 | 默认 | 语义 |
|---|---|---|
| `kbengine.core.backend` | `"ts"` | `ts` 单轨(现状真相,零参与);`rust` 保留值——被 serving 门禁拒绝,生效轨道仍 ts 并留 notice 存照;`shadow` 影子比对。enum 约束 + 任意非法值一律回落 `ts`(kill-switch 永远收得回来) |
| `kbengine.core.serverPath` | `""` | kode-server 二进制路径;仅 shadow 用,空 = 影子比对记 `rust-unavailable`,不启动进程 |

### 1.2 实现落点(file:line)

- `src/kodeCoreGate.ts:54` `resolveBackendMode`:仅 `shadow`/`rust` 两个字面量改变模式,其余(undefined/空串/拼错/大小写不符)全部回落 `ts`;`rust` 额外置 `rustServingGated=true`。

## 2. 回退方案(门 3)三件套

### 2.1 kill-switch(一键回 TS)

- 用户操作:`kbengine.core.backend` 改回 `ts`(或任意值——非法值也回落 ts,宁误杀不漏杀)。
- 生效路径:`kodeCoreGateWiring.ts:72` 配置监听 → `setConfig`(`kodeCoreGate.ts:240`)→ Rust 进程 dispose + 通道撤销;即时不重载窗口。
- Rust 进程此刻是否服务都无所谓:TS 从未停止服务(本 PR 内 TS 是唯一服务方),因此回退对用户**零可见差异**;未来 Rust 参与服务后,同一开关即时切断 Rust,请求回落 TS 真相。

### 2.2 shadow 模式(双跑比对,Rust 结果仅记录不发布)

- `backend=shadow` + `serverPath` 指向 kode-server:TS 照常服务;provider 侧经 `gate.compare()` 镜像同参请求(本 PR 落门与采集器本体,provider 逐面接线属 parity 扩面后续单)。
- 差异日志:`src/kodeCoreGate.ts:140` `ShadowDiffLog`(有界环形 500 条,seq 单调,可订阅);装配面订阅到输出通道「KBEngine Core Shadow」(wiring `:44-52`),每行 `#seq | ISO 时间 | verdict | method | uri | detail`;diff 的 detail 为**首个分歧路径 + 双方截断预览**(`:98` `firstDiffPath`,键序不敏感规范比较)。
- summary 汇总(`total/match/diff/failure`)供回退演练判据与 parity 报告直接取数。

### 2.3 回退演练脚本与判据(门 3 第三缺口)

演练步骤(可重复执行):

1. `kbengine.core.backend=shadow`、`kbengine.core.serverPath` 指向 `cargo build -p kode-server` 产物;重载或等配置监听生效。
2. 正常使用 hover/补全等 TS 功能(与平时无差别);打开「KBEngine Core Shadow」通道观察 verdict 流。
3. 触发 Rust 侧故障面(改错 `serverPath`、kill 二进制、把 `shadowTimeoutMs` 调到 0)——验证差异日志只记 `rust-unavailable`/`rust-error`/`rust-timeout`,TS 功能零异常。
4. **kill-switch 演练**:`backend` 改回 `ts` → 通道消失、Rust 进程退出、TS 功能照常(装配面判据由 `tests/kodeCoreGateWiring.test.ts`「通道就绪;配置变更切回 ts 即撤通道」锁死)。

判据(全绿才算演练通过):

- [ ] 步骤 3 全程 hover/补全/诊断结果与纯 `ts` 模式逐字节一致(compare 恒返回 tsResult 原引用,单测锁定);
- [ ] 差异日志 summary 里 `failure` 条目的 detail 均可归因 rust 侧,无一条影响服务;
- [ ] kill-switch 后 `gate.state.clientAlive=false` 且新请求不再进差异日志;
- [ ] 演练全程无弹窗、无进度条、无新增诊断(用户无感)。
